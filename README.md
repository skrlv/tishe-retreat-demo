# ТИШЕ — северный ретрит

Завершённый демонстрационный сайт вымышленного камерного отеля на природе. Русский интерфейс, самостоятельная визуальная концепция: хвойный зелёный, песочный фон, крупная антиква, отдельные панели текста и пейзажа, природный ритм и атмосферная фотография.

Публичный адрес: https://skrlv.github.io/tishe-retreat-demo/

Репозиторий: https://github.com/skrlv/tishe-retreat-demo

## Возможности

- Три дома с подробными карточками в нативных диалоговых окнах.
- Выбор дат и количества гостей с проверкой календарных дат, прошедших дат, продолжительности 1–30 ночей и вместимости дома.
- Демонстрационный расчёт стоимости по условным тарифам и итоговое окно с количеством ночей.
- Живое резюме выбранного отдыха с количеством ночей, гостей и стоимостью.
- Галерея, переключаемые истории «Утро / День / Вечер» с навигацией стрелками, раскрывающиеся ответы на вопросы.
- Мягкое появление разделов, плавное приближение пейзажа, индикатор чтения и реакции на наведение; движение отключается при reduced motion. Содержимое остаётся видимым без анимаций и JavaScript.
- Адаптивный интерфейс, клавиатурная навигация, reduced motion, локальные фотографии.

Это статический сайт без сборки и сторонних зависимостей. Для просмотра запустите из этой папки:

```sh
python3 -m http.server 4176
```

Откройте http://127.0.0.1:4176/ . Двойной щелчок по HTML не подходит для модульного JavaScript. Для тестов нужен Node.js:

```sh
npm test
npm run check
```

Все пути к стилям, скриптам и изображениям относительные, поэтому сайт работает в подпапке GitHub Pages.

## Границы демонстрации

Отель и дома вымышлены. Тарифы, вместимость, площади, оснащение и описания — примеры для портфолио. Фотографии иллюстрируют настроение. Доступность не проверяется. Бронирования, отправка данных, платежи, учётные записи и хранение персональных данных отсутствуют.

Источники фотографий — в ASSETS.md. Системные шрифты не требуют внешних запросов.
